# Company Policy Handbook

## Remote Work Policy
Employees may work remotely up to 3 days per week. Remote work requests must be approved by your direct manager. All remote workers must ensure a stable internet connection and attend mandatory team sync meetings.

## Leave Policy
- Annual leave: 15 days per year
- Sick leave: 10 days per year
- Unused leave does not roll over to the next year

## API Documentation v2.1
Our main API endpoint is https://api.company.com/v2. All requests require an API key in the header: `Authorization: Bearer <key>`. Rate limit: 100 requests per minute. Deprecated: v1 API will be shut down on March 1, 2025.

## Security Guidelines
- Use MFA for all company accounts
- Never share credentials via email or chat
- Report suspicious emails to security@company.com
- Password must be at least 12 characters with special symbols
